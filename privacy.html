개인정보처리방침 (Privacy Policy)

market-shorts 는 채널 운영자 본인만 사용하는 개인용 업로드 도구입니다.

  • YouTube API 를 통해 운영자 본인 계정의 동영상 업로드와 업로드한 동영상 상태 확인에만 접근합니다.
  • 다른 사용자의 개인정보를 수집·저장·판매·공유하지 않습니다.
  • 인증 토큰은 운영자 본인의 컴퓨터에만 저장되며 외부로 전송되지 않습니다.
  • 권한은 Google 계정 설정(보안 → 타사 앱 연결)에서 언제든 해제할 수 있습니다.

market-shorts is a personal tool used only by the channel owner. It accesses the YouTube API solely to upload the owner's own videos and check their status. It does not collect, store, sell or share anyone's personal data. Authorization tokens are stored only on the owner's computer. Access can be revoked at any time in Google Account settings.

This app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
